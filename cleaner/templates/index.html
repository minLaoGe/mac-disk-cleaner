Mac 大文件清理助手 v1.2.0

Mac Disk Cleaner · 智能磁盘与模型清理中枢

Mac 大文件清理助手 是一款专为 macOS 系统量身打造的磁盘大文件排查、大模型权重清理与应用缓存治理工具。支持优雅的 Web 可视化面板，还原生集成了标准 MCP (Model Context Protocol) 协议。

核心特性与技术亮点
  • 高速智能跳过微型依赖：全盘扫描自动跳过 node_modules、.git、.nvm 等数百万极碎文件，极速定位大文件。
  • 结果持久化与免丢缓存：扫描数据与筛选配置自动在服务端与本地双重缓存，刷新页面不丢失。
  • 废纸篓优先安全保护：日常删除对接 macOS 系统废纸篓机制，随时可一键放回原处，核心系统路径拦截防误删。
  • 大模型原生 MCP 支持：提供 6 大标准 MCP 工具，无缝接入 Claude、Cursor、Antigravity，用自然语言对话管理磁盘。
